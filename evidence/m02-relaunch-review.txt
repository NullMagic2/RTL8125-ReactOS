Concrete VFIO preflight correction:

container owner. The tool now only opens an otherwise eligible group's character
node read-only/no-follow, invokes VFIO_GROUP_GET_STATUS, requires VIABLE and no
CONTAINER_SET flag, then closes it. It never requests a container, device FD,
IOMMU setup, interrupts, reset or DMA mapping. Failures reject readiness. The
result is a snapshot; another process may change state before a future launch.
