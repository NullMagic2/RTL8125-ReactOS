Module: rtl8125.evidence.m03
Purpose: Bound M03 implementation claims to source, model and genuine-SDK evidence.
Created: 2026-10-24

Gate 1: COMPLETE in implemented callable modules. RegisterSession serializes a
whole sequence, including MAC OCP read/modify/write and firmware MDIO page state.
Checked 8/16/32-bit native M02 accessors back the platform bridge. PHY OCP, MAC
OCP, EPHY, EXGMAC ERI, RTL8125 paged MDIO and firmware MAC-MCU commands preserve
the pinned Linux command encoding/polarity/delays. Polls have finite attempts;
all operations have elapsed, delay and operation budgets; the first I/O error,
removal or timeout latches and blocks subsequent writes. Session claim/release
is explicit and concurrent claim fails. Native code enforces PASSIVE_LEVEL.

Gate 2: PENDING. Full RTL8125B PHY tuning and A/B EPHY tables are ported, with
firmware followed by bounded soft-reset polling, parameter writes, legacy force
mode, ALDPS and B PHY EEE tuning in Linux order. The overall gate still requires
A PHY tuning and complete A/B reset, OOB/FIFO, ASPM/PCI/CSI and common MAC start
sequencing, legacy descriptor mode, MAC EEE policy and controlled integration.
The EPHY function explicitly requires its caller to set ASPM latency first.
These sub-sequences are never advertised as complete MAC initialization.

Gate 3: COMPLETE in source and genuine-SDK ABI fixture. Linux raw/headered
firmware formats are bounded to 1 MiB; bytewise decoding avoids alignment
assumptions. Header checksum, code extents, nonempty code and all Linux opcode
and branch rules are checked before any execution. Header/code overlap is
additionally refused. All Linux opcodes execute with step and elapsed budgets;
all delays share the session budget. Execution revalidates borrowed file bytes.
NT acquisition selects only core firmware_name(A/B) under the fixed path
SystemRoot/system32/drivers, opens a read-only synchronous kernel handle,
queries/caps file size, reads a private nonpaged copy, validates it, closes every
opened handle and frees partial storage. There is no arbitrary caller pathname.
No firmware is distributed with the driver. No actual NT file call was executed:
ABI fixture file imports are mocks. This gate does not imply physical execution.

Gate 4: PENDING. No autonegotiation, selected-card link transitions or truthful
10/100/1000/2500 status integration yet. Model sequencing cannot satisfy the
physical-card portion. Dedicated card is unavailable; host NIC was never touched.

  Leak detection disabled because tracing prevents LeakSanitizer, as baseline.
  Includes indirect failure/time/removal budgets, exclusion, exact B PHY tuning,
  every I/O failure in EPHY+B PHY sequence, header truncations, control flow,
