Implemented code:
- src/core/receive.hpp/.cpp extracts the pre-existing single receive decoder
  unchanged from descriptor.hpp/.cpp into a container-free shared native contract.
  Native SDK SAL macros clash with libstdc++ array internals; the offline encoder
  remains host-only and is never a live ring. No duplicate decoder was introduced.
- poll_receive consumes at most min(budget,256) acquired completions through
  existing DmaOwner; rejects error/fragment/bounds/FCS errors, runt frames under60
  and VLAN/QinQ. It copies into separate fixed nonpaged storage before indicating
  or rearming; OWN remains clear throughout the indication callback.
- Startup allocates one NDIS packet and one MDL once, with single-element packet/
  buffer-pool requests. Each received packet uses NDIS_STATUS_RESOURCES and full
  lookahead: synchronous consumption permits immediate reuse, with no miniport
  per-packet allocation, ReturnPacket callback or retained NDIS receive packet.
  Packet length/cache, Ethernet header size, checksum and VLAN metadata are reset
  before each indication. Partial pool/packet/MDL failures unwind exactly once.
- Actual ReactOS NdisAllocateBufferPool returns SUCCESS and null handle; acquisition
  is tracked separately and NdisAllocateBuffer accepts that handle. Both actual
  null and conventional nonnull handle behavior are covered by real-SDK fixtures.
- Bounded current-filter/multicast-list query/set OID helpers support directed,
  broadcast, exact multicast list(32), all multicast and promiscuous filters.
  Invalid flags, lengths, unicast/broadcast list entries and oversize lists leave
  software state unchanged. Hardware multicast hash uses Linux ethernet CRC,
  word reversal/byte swaps and MAR4-before-MAR0 ordering. Software exact filtering
  eliminates hash collisions. Query max-list matches32; no offloads are advertised.
- Explicit startup clears RX error/runt acceptance and inner/outer VLAN extraction,
  disables RxChkSum, programs RxMaxSize1519 and arms existing DMA RX slots.
  Filter updates preserve unrelated register bits and flush posted writes; partial
  hardware programming failure stops admission and leaves accepted software state.
