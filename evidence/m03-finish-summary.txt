Implemented source:
  src/hardware/registers.*: existing exclusive sticky-error register sessions
  now also own bounded native PCI configuration and exact CSI command encoding,
  including actual PCI function, completion polarity, delays and byte enables.
  Native extended config rejection falls back to CSI for the 0x70f ASPM latency
  byte, preserving other bytes. All operations retain finite count/time budgets.

  src/hardware/phy.*: complete pinned RTL8125A PHY sequence added alongside B:
  all paged masks, the two B87 parameter pairs, exact fifteen coefficient values
  followed by twenty-five zero writes, A43 parameters, exact firmware placement,
  bounded firmware-reset polling, post-firmware A tuning, 10M GPHY, ALDPS and
  A EEE tuning. Existing B tuning and both EPHY tables remain source-exact.

  src/hardware/device.*: complete callable A/B device services added. They check
  the exact PCI identity, traverse the PCIe capability list with cycle/length
  bounds, disable PCIe ASPM/CLKREQ with readback, set/read back 4096-byte MRRS,
  program initial A/B RxConfig, mask/ack IRQs and commit posted writes, perform
  RXDV gating, A/B FIFO readiness (including B StopReq/IntrMitigate), OOB exit,
  link-list FIFO setup and bounded MAC reset. The backup/current station address
  is read bytewise, validated as nonzero unicast and programmed in Linux order;
  no address is invented. The native card reports PHY ID 0x001cc840 via read-only
  Linux sysfs; the implementation accepts Linux's internal generic 0x001cc800 or
  B 0x001cc840 identities and requires actual 2.5G capability. PHY resume clears
  power-down and preserves rtlgen_resume's 20 ms delay before tuning. Tuning is
  followed by a bounded soft reset and real autonegotiation advertisement.

  The full A/B MAC start configuration ports CPlus policy, EEE idle timer,
  interrupt coalescing disable, ASPM latency before EPHY, complete common MAC
  OCP ordering/masks, UPS/L23 handling, exact e614/e63e generation differences,
  legacy descriptor selection, eb54 pulse, e00e poll, MAC EEE timing tuning and
  RXDV ungating. Initial implementation deliberately leaves platform/chip ASPM
  and CLKREQ disabled: NT platform-wide ASPM arbitration is not qualified. Both
  standard EEE advertisements and pause are disabled; Linux PHY/MAC tuning is
  retained. Advertised 10/100 modes derive from actual BMSR abilities, 1000 full
  from extended abilities, and 2500 full from actual Realtek capability. No 5/10G,
  hardware checksum, TSO, VLAN stripping or jumbo feature is advertised.

  initialize_device leaves initialized=true, running=false, IRQs masked and
  engines stopped. Explicit activate_device requires two disjoint aligned genuine
  below 4 GiB ring intervals, writes high halves before low halves, sets the bounded
  receive maximum_frame_size+FCS+1 (1519) independently of the fixed 2048-byte
  DMA arena and starts TX/RX with software offload policy. Preconfigured M06
  directed/broadcast/multicast/promiscuous accepts survive activation; error/runt
  accepts are cleared. IRQ enable belongs to M07. Caller must already expose/arm the
  actual DMA owner and qualify IRQ/recovery services. No production Initialize
  call exists while those prerequisites remain absent.

  LinkState reads double BMSR latch-low status, requires autonegotiation enabled
  and complete, decodes actual downshift rate from the Linux RTLGEN_SPEED_MASK
  register and reads actual MAC duplex/link status. A stable final BMSR reread is
  required. Down/error/incomplete negotiation clears speed/duplex; unsupported
  5/10G encodings and impossible half duplex at 1000/2500 are rejected.

  src/reactos/hardware_init.*: genuine NT/NDIS bridge implements
  initialize_hardware, activate_hardware and query_hardware_link. HardwareAccess
  owns the stable assigned mapping, actual adapter handle and PCI function;
  FirmwareBlob records the selected immutable version. Wrong IRQL, mismatched
  firmware identity and concurrent claim reject before access. Native full-init
  budget is 900000 operations, 9 s delay, 15 s elapsed; every indirect poll is finite.
  On a started failure, the failed scope releases before a fresh bounded scope
  masks IRQs, rejects RX, stops engines and locks config. Recovery_required stays
  set. Containment never certifies DMA retirement or permits buffer release.
